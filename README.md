# Hackathon-Project-Share

Hackathon SafeRoute Project

Project Description

This project will use 2 points A and B to create a route and colour grade it based off the safety score using data from the police API. The project was made through pure vanilla JS, HTML and CSS.

We faced a lot of tough challenges throughout this project , through figuring out how to caculate the amount of crime through a route and implementing it. That was our biggest struggle.

How to run the project

Since this is a local repository you will have to clone the repositroy so it is local to your machine, load the webpage and it will run.

How to use the project

Enter a starting and ending location , press the " find safe route " button and go ahead heres your safe route.
